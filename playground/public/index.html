How it works

  1. Source files (JSON records) live anywhere: git, CMS cloud, disk.
  2. Sync parses them into one SQLite table, then derives hierarchy, effective status, URLs and search text — inside a single transaction.
  3. Queries compile to SQL, including relations (parents, children, siblings) and full-text search.
  4. Mutations run as transactions with validation; failures roll back.
  5. Overlays give previews and the Next.js handler isolated write layers over a readonly database.
